# Una línea por negocio. Los campos van separados por | (barra vertical):
#   nombre | rubro | latitud | longitud | descripcion (qué vende u ofrece) | telefono | direccion | horario | destacado | foto
#
# - rubro: GASTRONOMIA, FARMACIA_SALUD, MODA_ROPA, CAMBIO_MONEDA, TRANSPORTE,
#          ALOJAMIENTO, ABARROTES, TECNOLOGIA, SERVICIOS u OTRO
#          (si necesitas otro rubro, escríbelo y lo agrego a la app)
# - latitud y longitud: decimales con PUNTO, negativos en Bermejo (ej: -22.7333 | -64.3417)
# - descripcion: qué vende u ofrece el negocio, en una frase corta.
# - telefono: número de contacto (celular/WhatsApp). Déjalo vacío si no hay.
# - direccion: calle y referencia, texto libre. Déjalo vacío si no se conoce.
# - horario: texto libre (ej: 08:00 - 20:00). "Consultar" si no se conoce.
# - destacado: SI o NO (SI = dispara la notificación de cercanía).
# - foto (OPCIONAL, décimo campo): nombre del archivo en app/src/main/res/drawable-nodpi/, en
#   minúsculas, sin espacios, tildes ni símbolos (ej: aurora_2.jpg; la extensión es opcional).
#   Si no hay foto, deja el campo vacío o borra el último |: la app muestra el ícono de su rubro.
#   Para agregar una foto: copia el JPG a esa carpeta con un nombre seguro y escríbelo aquí.
# - Las líneas que empiezan con # se ignoran.
#
